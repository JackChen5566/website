# DriveMax Car Website

這是一個純 HTML / CSS / JavaScript 的汽車銷售網站範例，可直接部署至 GitHub Pages。

## 結構

campingWebsite/
├── index.html
├── about.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
    ├── logo.svg
    ├── camping.svg
    ├── sedan.svg
    ├── suv.svg
    └── sport.svg

## GitHub Pages

1. 將 campingWebsite 內容放進 GitHub Repository。
2. Git commit / push 到 main branch。
3. Repository → Settings → Pages。
4. Source 選 Deploy from a branch。
5. Branch 選 main / root。
